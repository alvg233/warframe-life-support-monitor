# v1.9.3 发布说明

## 识别率修复（重点）

- **移除「自动收敛识别框」**：该机制会把区域越收越小（日志中出现过 0.038 宽的极小块），
  之后连续识别失败，直到重建引擎才恢复。现改为始终使用用户框选的区域，实测成功率 20/20。
- **重排识别变体**：实测检测器在 1 倍尺寸下完全检不出文字，2x/3x 才稳定命中；
  原回退顺位中的 1x 项已替换为 3x，并加入 CLAHE 变体。
- **时间区域可自动定位**：新增「自动定位时间」按钮；时间区域连续 5 次读不到时也会自动重新定位并保存。
- 时间读取改为 2x → 3x → rec_only 依次尝试，实测 10/10 成功，单次约 0.18 秒。
- 时间读取默认改为每 3 轮一次（原来 2 轮）。

## 安装

下载 `Warframe-LifeSupport-Monitor-Setup-1.9.3.exe` 运行即可，安装时可选择路径，
桌面与开始菜单快捷方式默认勾选。
