屏幕数值监控 · 使用说明（Warframe 生存任务）
================================================

一、用途
  用于 Warframe 生存任务的挂机监测：定时识别画面左上角的「维生系统」百分比与任务计时，
  数值过低时本地记录、截图并通过钉钉群机器人提醒；可设置“急停”在氧气归零或到点后暂停游戏。

  本工具不联网、不上传数据。截图与日志全部保存在本机，钉钉消息只发送到你自己的群机器人。

二、安装
  1. 双击安装包，按提示完成安装（安装到当前用户目录，不需要管理员权限）。
  2. 桌面与开始菜单会生成快捷方式。
  3. 游戏请使用「无边框窗口」或「窗口化」模式；独占全屏无法截取窗口画面。

三、首次设置（向导共四步）
  1. 选择窗口：在列表中选择 Warframe，程序自动记录窗口标题与进程名。
  2. 框选区域：拖出矩形，覆盖「维生系统」下方那一行百分比（含 % 号）。松开鼠标后程序会自动识别一次，
     并在下方显示识别结果；识别失败可重新框选或点「自动校准」。
  3. 设置阈值：预警线（默认 50）与报警线（默认 35）。跌破预警线记录日志与截图；
     跌破报警线额外发送钉钉。预警线必须高于报警线。
  4. 填写钉钉：粘贴群机器人 Webhook；若机器人启用了加签，同时填写密钥，然后点「发送测试」。

四、日常使用
  1. 点击「开始监控」，数值与任务时间会持续刷新。
  2. 状态灯含义：正常 / 预警 / 报警 / 未知（未读到数值）。
  3. 底部事件行会说明当前异常原因，例如区域未框好、游戏处于菜单、截图通道不匹配。
  4. 关闭主窗口会退出程序；最小化则继续监控。

五、报警规则
  - 只按“穿越”触发：从上方跌破预警线/报警线各触发一次，不会每轮重复。
  - 持续低于报警线时，按「重提醒间隔」（默认 30 分钟）再次提醒，并附最新截图。
  - 回升超过报警线会记录“恢复正常”，可选择一并发送钉钉。

六、急停
  触发条件可多选：百分比归零、时间到达指定分钟数。
  执行动作：切换到游戏前台 → 点击游戏窗口（使游戏接收键盘）→ 按 ESC → 连续识别确认。

  - 连续 5 次都识别不到数值：判定急停成功，随后停止监控。
  - 任意一次读到数值：判定未确认，事件行会说明原因。
  - 勾选「急停后等待下一局并自动恢复监控」后，检测到计时器归零会自动恢复监控。

  时间读数带合理性校验：只接受缓慢递增的计时；明显跳变会挂起一轮确认；
  “少一位”的读数（例如 226:11 读成 26:11）判为误读，不会把正确值覆盖掉。

七、悬浮窗
  高级设置 → 运行与日志 → 勾选「最小化时显示悬浮窗」。
  主窗口最小化且正在监控时，屏幕指定位置显示当前百分比与任务时间。
  悬浮窗置顶、半透明、鼠标穿透，不接收点击，也不影响其他窗口操作。

八、记录与截图位置
  数据目录：%APPDATA%\ScreenOcrAlert
    报警记录  logs\events.jsonl   仅记录跌破阈值等业务事件
    采样记录  logs\samples.log    每次采样一行：时间 + 数值，失败记为 fail
    技术日志  logs\app.log        启动、停止、报警、发送失败
    截图      snapshots\日期\     文件名即实际时间，报警截图带 _EX 后缀
  截图默认保留 30 天，可自动清理。

九、问题反馈
  高级设置 → 运行与日志 → 「导出诊断包（发给作者）」，会生成 logs\diagnostics\diag-*.zip。
  压缩包内 Webhook 与密钥已打码。把该文件发给作者即可。
  作者 QQ：494735622

十、常见问题
  1. 识别不到数值：确认游戏不在菜单或加载画面；点「自动校准」；确认截图通道为「游戏窗口」。
  2. 截图全黑：游戏为独占全屏，请改为无边框窗口，或把截图通道设为「整屏」。
  3. 钉钉未收到：先发送测试消息；技术日志会记录 errcode（加签错误、关键词不匹配等）。
  4. 急停没有按到游戏：确认「切前台后先点一下游戏窗口」已勾选；点击位置默认在左上角「生存」附近。
  5. 安装被系统拦截：程序未购买代码签名证书，选择「更多信息 → 仍要运行」即可。
  6. 挂机时 CPU 偏高：连续识别失败会自动退避（隔轮检查、降低识别次数），画面恢复后自动回到正常频率。
