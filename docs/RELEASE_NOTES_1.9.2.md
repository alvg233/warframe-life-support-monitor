# v1.9.2 发布说明

## 新增

- 启动监控前检查权限：若游戏以管理员身份运行而本程序不是，弹窗提示"急停会失败"，并给出解决方式。
- 安装程序：显式提供「选择安装位置」页面，可自定义安装路径。
- 安装程序：桌面快捷方式、开始菜单快捷方式两项改为默认勾选（可取消）。

## 修正

- 安装信息补全：发布者、项目主页、问题反馈、更新日志地址指向仓库。
- 安装程序限定 Windows 10 及以上。
- 修复界面模块一处语法错误（1.9.1 构建中断，本版重新构建）。

## 安装

下载 `Warframe-LifeSupport-Monitor-Setup-1.9.2.exe` 运行即可。
程序未购买代码签名证书，首次运行可能提示 SmartScreen，选择「更多信息 → 仍要运行」。
