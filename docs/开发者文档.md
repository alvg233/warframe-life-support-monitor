# 开发者文档

面向二次开发与维护：模块结构、配置字段、事件协议、识别管线、构建与发布。

## 1. 运行环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（依赖 Win32 截图与输入注入） |
| Python | 3.11+（开发使用 3.13） |
| 依赖 | rapidocr（onnxruntime）、numpy、Pillow、mss、psutil、requests、pystray |
| 显示 | 缩放 100%~200% 均可（启动时声明 DPI 感知，内部使用物理像素） |

本地开发时依赖可安装到 `.vendor`，程序启动会自动把 `.vendor` 加入 `sys.path`。

## 3. 运行流程

```
main()
 ├─ enable_dpi_awareness()
 ├─ applog.setup(log_dir) → app.log / samples.log
 ├─ _install_crash_hooks() → crash.log + 首次异常自动导出诊断包
 ├─ config.load() → deep_merge(默认配置, 用户配置)，按规则补齐新字段
 └─ AppUI()
     ├─ MonitorService(cfg_provider, on_event, states=...)
     └─ 用户点击「开始监控」→ MonitorService.start()（daemon 线程）
```

采样线程每轮：

```
tick()
 ├─ _components(cfg)        按窗口签名重建截图器（配置变化时才重建）
 ├─ 遍历启用的规则
 │   └─ _check(rule)
 │       ├─ grab_region_auto(区域)          窗口截图 / 整屏截图
 │       ├─ 黑屏判断 → 只记录一次，不报警
 │       ├─ emergency.check()               时间/归零触发（在变化检测之前）
 │       ├─ 变化检测（指纹差异）→ 无变化可跳过 OCR
 │       ├─ reader.read()                   识别 + 降速校验 + 重读
 │       ├─ 失败 → 连续失败退避 / 重建引擎（≥10 分钟一次）
 │       └─ 成功 → policy.on_read()         分带穿越、截图、钉钉
 └─ stop.wait(interval - 已用时)
```

## 4. 配置字段

配置文件为 JSON。加载时与默认配置做深度合并，`rules` 数组按元素补齐新字段（不覆盖用户值）。
保存为原子写入，覆盖前保留 `config.json.bak`。

### 4.1 顶层

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `version` | int | 2 | 配置结构版本 |
| `app` | object | - | 见 4.2 |
| `sample` | object | - | 见 4.3 |
| `guard` | object | - | 见 4.4 |
| `snapshot` | object | - | 见 4.5 |
| `dingtalk` | object | - | 见 4.6 |
| `rules` | array | 1 条 | 规则数组，见 4.7 |

### 4.2 `app`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `low_priority` | bool | true | 进程优先级降到 BELOW_NORMAL |
| `start_monitoring` | bool | false | 启动后自动开始监控 |
| `show_overlay` | bool | true | 显示区域边框 |
| `ui_mode` | str | `simple` | `simple` / `advanced` |
| `wizard_done` | bool | false | 是否完成过设置向导 |
| `hud.enabled` | bool | true | 最小化时显示悬浮窗 |
| `hud.position` | str | `顶部居中` | 顶部居中 / 左上 / 右上 / 左下 / 右下 |
| `hud.opacity` | float | 0.78 | 悬浮窗不透明度（0.2~1.0） |
| `hud.font_size` | int | 20 | 数值字号（12~60） |

### 4.3 `sample`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `interval_sec` | float | 1.5 | 采样间隔（最小 0.5） |
| `change_detection` | bool | true | 画面无变化时跳过 OCR |
| `diff_threshold` | float | 1.5 | 指纹差异阈值（0~255 均值差） |
| `force_ocr_sec` | float | 600 | 最长强制 OCR 间隔 |
| `retry_count` | int | 2 | 读数可疑时的重读次数 |
| `retry_gap_sec` | float | 0.35 | 重读间隔 |
| `log_enabled` | bool | true | 是否写 samples.log |

### 4.4 `guard`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `max_drop_per_1_5s` | float | 1.0 | 1.5 秒内允许的最大下降（按实际间隔等比放大） |
| `drop_tolerance` | float | 1.0 | 下降容差，避免边界抖动误判 |
| `agree_tolerance` | float | 1.0 | 重读一致判定容差 |
| `min_confidence` | float | 0.45 | 采纳识别结果的最低置信度 |

下降判定：`last - value > max_drop * (elapsed / 1.5) + tolerance` 记为疑似错读。

### 4.5 `snapshot`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | true | 是否截图 |
| `backend` | str | `window` | `window`（PrintWindow）/ `desktop`（整屏）/ `auto` |
| `window_title` | str | `""` | 窗口标题（与进程名二选一或同时） |
| `process_name` | str | `""` | 进程名，例如 `Warframe.x64.exe` |
| `dir` | str | `snapshots` | 截图子目录（相对数据目录） |
| `keep_days` | int | 30 | 截图保留天数 |

### 4.6 `dingtalk`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |

## 5. 事件协议

`MonitorService(on_event)` 向 UI 发送字典事件，`type` 取值：

| type | 字段 | 含义 |
| --- | --- | --- |
| `sample` | `rule` `value` `text` `score` `zone` | 一次成功读数；`value=None` 表示疑似跳变待确认 |
| `time` | `seconds` `text` | 时间区域读数 |
| `notify` | `message` | 已发送钉钉消息（或本地提示） |
| `emergency` | `success` `reason` `message` | 急停结果 |
| `emergency_stage` | `message` `running` | 急停阶段进度；`running=True` 表示正在执行 |
| `stopped` | `message` | 监控因急停成功而停止 |
| `error` | `message` | 可读错误提示 |
| `region` | `rect` | 区域实际落点，用于同步边框 |

## 6. 日志格式

### 6.1 `events.jsonl`
一行一个 JSON：`time` `epoch` `event` `host` `pid` + 事件字段。仅记录业务事件：
`warn_cross` `alert_cross` `alert_repeat` `recover` `emergency_stop`。超过 5 MB 滚动为 `.1`。

### 6.2 `samples.log`
`YYYY-mm-dd HH:MM:SS  <数值>`；识别失败为 `fail  <原因>`；疑似跳变以 `?` 结尾。

### 6.3 `app.log`
关键事件（启动、停止、报警、发送失败、重建引擎）。技术细节为 DEBUG 级别，默认不落地。

### 6.4 消息模板字段
`{name}` `{warn}` `{alert}` `{value}` `{prev}` `{time}` `{host}` `{snapshot}` `{text}`；
急停模板额外支持 `{reason}` `{reads}` `{detail}` `{result}`。

## 8. 识别管线

1. **截图**：`window` 通道用 `PrintWindow(PW_RENDERFULLCONTENT)` 取窗口位图，按"位图尺寸/窗口矩形"换算缩放后裁剪；
   `desktop` 通道用 mss 直接取屏幕区域。
2. **OCR 变体**（`ReadGate._variants`，按顺序）：
   检测器 2x → 检测器 1x → CLAHE + 检测器 → rec_only 1x → rec_only 2x。
   每个变体都必须解析出合法数字且置信度达标才采纳，否则继续下一个。
3. **降速校验**：见 4.4；可疑时重读 `retry_count` 次，要求相邻读数差 ≤ `agree_tolerance` 才采纳，
   否则进入"连续两轮同值"确认；两轮仍不一致则按真实跳变处理。
4. **自动重定位**：小区域连续失败时，在 `search_zone` 内定位含 `%` 的行，换算为新的 ratio 区域并缓存。
5. **退避**：连续 3 次失败后只尝试前两个变体、不重读，并隔轮检查；连续 5 次失败重建 OCR 引擎（≥10 分钟一次）。

## 9. 急停状态机

```
idle ──触发(归零/时间)──▶ running(前台→点击→按键→连续识别)
                              │
              ┌───────────────┴───────────────┐
        全部读不到(成功)                  读到数值(未确认)
              │                               │
         停止监控 + 钉钉                   保持 fired 锁
              │
       auto_rearm → 等待计时器归零 → 复位状态 → 重新开始监控
```

互斥：`EmergencyStopper._run_lock` 保证同一时刻只有一次执行；手动执行与自动触发不会叠加按键。
时间读数校验：只允许缓慢递增（`elapsed*3+5` 秒），跳变挂起一轮确认，下降 60 秒以上视为换局需重读确认，
"少一位"（旧值 > 600 秒且新值 > 300 秒且差值 > 600 秒）直接判误读。

## 10. 悬浮窗与区域边框

两者都是 `Toplevel`，通过 `wininput.make_click_through()` 实现"仅可见"：

- `WS_EX_TRANSPARENT`（鼠标穿透）、`WS_EX_NOACTIVATE`（不抢焦点）、`WS_EX_TOOLWINDOW`（不进 Alt+Tab）；
- 沿 `GetParent` 逐层设置（Tk 的 Toplevel 外层还有包装窗口，只设内层仍会吃掉点击）；
- **不要**修改 `WS_EX_LAYERED`：改写该位会清空 Tk 的 `-alpha` / `-transparentcolor`，窗口会变成不透明黑块。

定位用 `winfo_reqwidth/reqheight`（隐藏状态下 `winfo_width` 为 1）。

## 11. 诊断包

`diagnostics.export(reason)` 生成 `logs/diagnostics/diag-<时间>.zip`：

```
reason.txt   system.txt   config.json(脱敏)
logs/{app,startup,crash,samples,events}
snapshots/*.jpg（最近 3 张，宽度 ≤1280，JPEG q72）
```

脱敏规则：键名包含 `webhook|secret|token|password|sign` 的值替换为 `***已打码（原长度 N）***`。

## 13. 构建与发布

```bat
install_deps.bat         :: 依赖装入 .vendor（清华镜像）
build_exe.bat            :: PyInstaller onedir → dist\ScreenOcrAlert，带图标与版本信息
build_installer.bat      :: Inno Setup → dist\installer\ScreenOcrAlert-Setup-<版本>.exe
```

注意：

- 构建产物可能被加上"低完整性级别"标签，导致双击无法运行；构建脚本内已调用
  `icacls /setintegritylevel M` 修复。
- 数据目录在 `%APPDATA%`，重新构建覆盖程序目录不会清掉配置与截图。
- 未购买代码签名证书时，安装包可能触发 SmartScreen 提示；本地自签名仅对本机有效。

## 14. 已知限制

- 仅支持单规则；`states` 中的失败计数由所有规则共享。
- 独占全屏无法通过 PrintWindow 截取窗口画面，需要无边框窗口或整屏通道。
- 计时器位置随窗口尺寸非线性变化，依赖 `search_zone` 自动重定位兜底。
- OCR 为单引擎串行调用（保证线程安全），识别一次约 0.3~0.6 秒。
